# Сценарий

Браузерный редактор сценариев — минималистичный, без аккаунтов и бэкенда. Шрифт Courier Prime 12pt, форматы Hollywood (US Letter) и российский (A4 / Kit-сценарист).

**[Открыть редактор →](https://dartino21.github.io/screenplay-editor/)**

> Если ссылка ещё не открывается, подождите минуту: GitHub Pages поднимается после первого деплоя.

---

## Возможности

- Страницы как на бумаге: 1 страница ≈ 1 минута экранного времени
- Два стандарта оформления: **US** и **RU**, с правильными отступами
- Умный поток: Enter ведёт дальше по правилам сценария, полоска типов под панелью
- Автодополнение сцен, локаций, имён персонажей
- Авто CAPS для сцены, имени и перехода; `(CONT'D)` / `(MORE)` на разрывах
- Навигатор сцен, режим фокуса, поиск и замена, переименование персонажа
- Подсветка орфографических и грамматических ошибок на русском и английском
- Импорт / экспорт [Fountain](https://fountain.io/), печать в PDF
- Автосохранение в `localStorage`
- **Мои сценарии** — несколько проектов в браузере; у каждого посетителя своя библиотека (GitHub Pages без сервера)

## Управление

| Клавиша | Действие |
|--------|----------|
| `Enter` | Следующий блок |
| пустой диалог + `Enter` | Следующий персонаж |
| `⌘` / `Ctrl` + `Enter` | Новый персонаж |
| полоска типов / `⌘1–6` | Сменить тип блока |
| `Tab` | Тип только на **пустой** строке |
| `⌘F` | Найти / заменить |
| `⌘O` | Мои сценарии |
| `⌘S` | Сохранить как копию |
| `Alt+F` | Режим фокуса |
| `\` | Навигатор сцен |
| `F1` | Справка |
| `?` | Печатается в тексте |

## Стек
